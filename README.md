# Proyecto_Final_Quimica_Organica
Base de datos de 200 reacciones (100 reacciones y 100 obtenciones) de 10 hidrocarburos (pentano, isopentano, hexano, heptano, octano, pent-2-eno, 2-metilpent-2-eno, hex-1-eno, ciclopropeno y ciclobuteno), consultadas en CAS SciFinder, con análisis gráfico en Python, informe en LaTeX y presentación en Power BI.
